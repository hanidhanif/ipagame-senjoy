# INSIDE YOU — Misi di Dalam Tubuh

Game edukasi berbasis web tentang sistem pencernaan manusia. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `INSIDE_YOU`.
3. Klik dua kali `index.html` untuk membuka game di browser.
4. Untuk mengunggah ke GitHub Pages, unggah `index.html`, `style.css`, `script.js`, dan folder `assets` ke repository.

## Kontrol
- `←` / `→` atau `A` / `D`: bergerak
- `SPACE` / `↑` / `W`: melompat
- Kumpulkan 3 bintang untuk membuka mini quiz.
- Jawab tiga pertanyaan untuk menuntaskan level dan membuka level selanjutnya.

## Fitur
- 5 level: Mulut, Kerongkongan, Lambung, Usus Halus, Usus Besar
- Gerakan karakter, lompatan, platform, dan collectible
- Mini quiz edukasi dengan umpan balik jawaban
- XP, koin, progres level, lencana, dan penyimpanan progres via localStorage
- Efek suara sederhana yang bisa dimatikan
- Tampilan responsif
- Tidak membutuhkan instalasi atau API eksternal

Catatan: font Nunito dimuat dari Google Fonts saat online; game tetap menggunakan fallback font jika offline.
